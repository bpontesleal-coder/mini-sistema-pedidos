# Mini sistema de pedidos

Simulação de uma loja online com carrinho de compras, feita com HTML, CSS e JavaScript puro.

**Acesse:** https://bpontesleal-coder.github.io/mini-sistema-pedidos/

## Funcionalidades

- Listagem de produtos
- Adição e remoção de itens no carrinho
- Cálculo automático do total
- Carrinho salvo no navegador com `localStorage`: os itens continuam lá ao recarregar a página

## Tecnologias

- HTML5
- CSS3 (Flexbox)
- JavaScript (manipulação do DOM, arrays e `localStorage`)

## Como executar

Basta abrir o arquivo `index.html` no navegador. Não há dependências nem etapa de instalação.

## Estrutura

```
index.html   estrutura da página
style.css    estilos
script.js    produtos, carrinho e cálculo do total
```
